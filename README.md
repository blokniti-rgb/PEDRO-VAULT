# PEDRO VAULT

**Your Personal Website Library.**

PEDRO VAULT is a simple and minimal website bookmark manager built to save, organize, and access your favorite websites in one place.

## Features

- Save websites with their name, URL, and description.
- Organize websites by categories.
- Search and filter saved websites.
- Mark websites as favorites.
- Edit and delete saved websites.
- Open websites directly in a new browser tab.
- Export and import JSON backups.
- Automatically save data using LocalStorage.
- No account or registration required.

## Technologies

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

## Getting Started

1. Open the PEDRO VAULT website.
2. Add your favorite websites.
3. Organize them into categories.
4. Search and access them whenever you need.

## Privacy & Storage

All saved websites are stored locally in your browser using LocalStorage.

Your library is private to your browser and is not automatically synchronized with other devices or users.

Use the Export feature to create a backup of your data.
